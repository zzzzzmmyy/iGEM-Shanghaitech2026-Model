# Fluorescence unmixing model

Estimate GFP-positive culture fractions from GFP and mCherry plate-reader measurements. This folder contains five files:

- `model.py`: raw-data extraction and evaluation of seven calibration models.
- `simulation.py`: the eight final Wiki figures, saved as PNG and SVG.
- `20260920.xlsx`: original pilot measurements.
- `20260921.xlsx`: original calibration measurements.
- `README.md`: installation, commands, inputs and outputs.

## Run

Open a terminal in this directory.

```bash
python -m pip install numpy==2.2.5 pandas==2.3.3 scipy==1.15.3 scikit-learn==1.7.2 matplotlib==3.10.9 openpyxl==3.1.5
python model.py --out output
python simulation.py --input output --out figures
```

The first script extracts both workbooks and fits models using the 20260921 data. The second generates eight plots, each as PNG and SVG, and writes the final M3 summary to `output/final_model_summary.json`.

## Inputs

Keep the two Excel files beside the scripts. To use another directory containing the same workbook names and plate layout:

```bash
python model.py --data-dir path/to/data --out output
```

The calibration set contains 63 measurements at 21 specified GFP volume fractions (0–1, step 0.05). The held-out set contains 8 measurements at fractions 0.075, 0.275 and 0.575. Six medium-only blank wells provide the channel baselines. All models use the original split, formulas and settings.

## Outputs

| Location | Contents |
| --- | --- |
| `output/df920_tidy.csv`, `output/df921_tidy.csv` | Raw readings and plate-map labels by well |
| `output/model_comparison.csv` | LOGO-CV and held-out R², RMSE and MAE for seven models |
| `output/model_blank_baseline.json` | Background means |
| `output/final_model_summary.json` | M3 parameters and metrics, generated by `simulation.py` |
| `output/*.pkl` | Intermediate tables used by the plotting script |
| `figures/` | Eight plots in PNG and SVG; generated locally |
