Fluorescence Unmixing Workbench

Mark blank and test wells on a 96-well plate, upload the GFP/mCherry fluorescence readings, and use the validated two-channel linear regression model (M3) to estimate the fraction of GFP-positive cells in each well.

1Design the plate layout

Drag across the plate to select multiple wells (marked as test wells by default); click a single well to cycle through Unused → Test → Blank. An example layout is already loaded; clear it to create your own.

2Import measurement data

Download a template matching your current plate layout, enter the Tecan readings, and upload it; you can also upload any spreadsheet that follows the format below.

The first row must contain the following three column headers (case-insensitive; extra columns are ignored). Well roles always follow the plate layout in Step 1; role information in the spreadsheet is not used:
